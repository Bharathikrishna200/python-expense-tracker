# 🧾 Python Expense Tracker

A beginner-friendly Python project to track monthly expenses.

## Features
- Input daily expenses for 30 days
- Calculates:
  - Total monthly expense
  - Average daily expense
  - Highest single-day expense
  - Number of days expense exceeded ₹1000
